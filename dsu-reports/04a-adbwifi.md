## 3. Что не проверено и почему
- **Загрузка мода `dsuset` и работа `am broadcast -a dsu.ADB_WIFI …`**: внешние моды грузятся только при старте Termux. Перезапуск Termux **завершит текущую сессию** (в ней работает Claude Code и я сам), поэтому я не перезапускал её без ведома пользователя. Нужно: пользователь перезапускает Termux; в новой сессии я проверю: `god-mods.log` (`external dsuset ok`), `am broadcast -a dsu.ADB_WIFI --es op get` (чтение), затем `--ei value 0` + `--ei value 1` **при выключенном адб-канале** (само по себе включение отладки app-процессом — главная цель 4а). 
- Поведение при ВЫКЛЮЧЕННОЙ отладке без возможности подключения shell (то, ради чего мод нужен): будет проверено после загрузки мода.
- Зависимость `adbfind` от сети: файл порта появляется, только если у телефона есть сетевой адрес (сейчас `10.14.238.211`); без сети — не проверялось.

## 5. Риски и находки вне плана
- **Главная находка:** `adb_wifi_enabled` можно переключать **от shell без UI**, и ОС поднимает отладку сама (новый порт ~10 с), сопряжение сохраняется. Это уже даёт сценарий «автоперезапуск отладки» через `dsu` (пока канал shell жив): `dsu -c 'settings put global adb_wifi_enabled 0; sleep 3; settings put global adb_wifi_enabled 1'`. Мод нужен для случая, когда отладка **выключена** и shell-канала нет.
- **Дефект `adbfind` (нет `adb-connect-port`)** теперь не воспроизводится: файл появляется, пока у устройства есть сеть (`10.14.238.211`). Гипотеза «нет сети → NSD ничего не находит» подтверждается косвенно (в первые сессии файла не было). Записано в `fix-adbfind-endpoint.md`.
- Приложение **`DEBUGGABLE`** (отладочная сборка): `run-as com.termux` с shell даёт доступ ко всем данным приложения → безопасность хранилищ слабее, чем у release (в рамках решения пользователя).
- Выключение отладки без возможности включить обратно (если мод не загрузится) оставило бы телефон без ADB до ручного включения; в моём шаге 2 отладка вернулась сама.
- Перезапуск Termux убьёт `socat`, `virgl`, Shizuku-сессии и т. п. (фоновые процессы приложения).
